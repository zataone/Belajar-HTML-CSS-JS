# EIGER Adventure Landing Page

A modern, responsive landing page for EIGER Adventure - Indonesia's premier outdoor gear and apparel brand.

## Features

- Modern, responsive design optimized for all devices
- Interactive product showcases with hover effects
- Animated sections using AOS (Animate On Scroll) library
- Product filtering by categories
- Interactive testimonial slider
- Store locator with animated map pins
- SEO optimized structure and metadata

## Technologies Used

- HTML5 semantic markup
- CSS3 with modern features (Flexbox, Grid, Animations)
- Vanilla JavaScript for interactivity
- Font Awesome for icons
- Google Fonts (Montserrat, Poppins)
- AOS Animation Library

## SEO Optimization

This landing page includes several SEO enhancements:

- Semantic HTML5 structure
- Comprehensive meta tags (description, keywords)
- Open Graph and Twitter card meta tags for social sharing
- Structured data (JSON-LD) for rich search results
- Mobile-friendly responsive design
- Optimized image alt tags
- Fast loading performance
- Well-structured headings (H1-H6)
